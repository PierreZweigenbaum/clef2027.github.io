PAN is a series of scientific events and shared tasks on digital text forensics and stylometry.

<!--more-->

## Tasks

The PAN Lab features ten different tasks:

{{< accordion  open_all="true" >}}
  {{< accordion-item title="Voight-Kampff Generative AI Detection" >}}
  Given a (potentially obfuscated) document, decide whether it was written by a human or an AI.
  {{< /accordion-item >}}
  {{< accordion-item title="Authorship Attribution to Large Language Models" >}}
  Given a text of unknown authorship and a set of candidate large language models, identify the model that generated the text.
  {{< /accordion-item >}}
  {{< accordion-item title="Text Watermarking" >}}
  Given a text, embed a watermark, then try to detect the watermark after a number of unknown perturbations.
  {{< /accordion-item >}}
  {{< accordion-item title="Multi-Author Writing Style Analysis" >}}
  Given a document, determine at which positions the author changes.
  {{< /accordion-item >}}
  {{< accordion-item title="Generative Plagiarism Detection" >}}
  Given a generated document and a corpus, retrieve all sources of the document from the corpus.
  {{< /accordion-item >}}
  {{< accordion-item title="Authorship Verification Efficiency" >}}
  Authorship Verification Efficiency (AVE) benchmarks how well AV systems balance predictive quality with fast and lightweight inference on German and English texts.
  {{< /accordion-item >}}
  {{< accordion-item title="Impostor Generation" >}}
  Develop models that generate impostor documents for the Impostors Method.
  {{< /accordion-item >}}
  {{< accordion-item title="Toxicity Detection across Cultures" >}}
  Given a text and a reader's cultural profile, determine whether the text contains content that is toxic or inappropriate within that cultural context.
  {{< /accordion-item >}}
  {{< accordion-item title="Digital Doppelganger Detection" >}}
  Given a text and user metadata, the task aims to distinguish genuine user-authored content from the text generated by a personalized AI agent (digital twin) designed to mimic that specific user.
  {{< /accordion-item >}}
  {{< accordion-item title="Language-Based Personality Profiling" >}}
  Given multiple documents per individual, predict individual personality trait scores.
  {{< /accordion-item >}}
{{< /accordion >}}
